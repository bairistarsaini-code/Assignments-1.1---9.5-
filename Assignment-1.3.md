Assignment 1.3 — Terminal & Developer Workflow
Task: Create a project folder structure using only the terminal/command line.
What to do:

1. Open the terminal.
2. Create a folder named `web-development-practice`.
3. Create `week-1`, `week-2`, and `week-3` folders inside it.
4. Create an `index.html` file inside each folder.
5. Practice navigating, renaming, and deleting folders using terminal commands.
6. Open the project folder in VS Code from the terminal.
Submission: A record of the terminal commands and a screenshot of the final folder structure.

---

## Answer / Commands

Open a terminal and run the following commands (Windows PowerShell):

```powershell
mkdir web-development-practice
cd web-development-practice
mkdir images
New-Item index.html, style.css, script.js
```

Check the structure with `dir`. Open the folder in VS Code using `code .` if the VS Code command is enabled. Keep HTML, CSS, JavaScript, and images in clearly named files. Take a screenshot of the terminal and folder structure.
