Assignment 3.1 — Two-Page Website with Working Links
What to build: A simple two-page website with working navigation links.
Steps:

1. Create `index.html` and `about.html` files.
2. Create the website name, introduction, and a navigation bar on the home page.
3. Add Home and About links in the navigation.
4. Connect both pages using `<a href="">`.
5. Add a link to any external website as well.
6. Use `target="_blank"` to open the external link in a new tab and `rel="noopener noreferrer"` for security.
Submission: Both HTML files and a screenshot of the working website.

---

## Answer / Implementation

**Approach:** Two-page navigation. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<!-- index.html -->
<nav><a href="index.html">Home</a> | <a href="about.html">About</a></nav>
<h1>Home Page</h1>
<!-- Create about.html with the same nav and an About heading. -->
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
