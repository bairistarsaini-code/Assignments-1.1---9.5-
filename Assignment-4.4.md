Assignment 4.4 — Metadata & Page Setup
What to build: Update your old HTML projects with proper metadata.
Steps:

1. Set UTF-8 for character encoding in every HTML file.
2. Add a mobile viewport meta tag.
3. Write a meaningful `<title>` for each page.
4. Add a meta description.
5. Add a favicon.
6. Verify that CSS links and file paths are correct.
Submission: Updated HTML files and a browser screenshot showing the favicon. Also submit the metadata code.

---

## Answer / Implementation

**Approach:** Metadata template. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0"><title>My Webpage | Portfolio</title><meta name="description" content="A short introduction to my portfolio and projects."><link rel="icon" href="images/favicon.ico"><link rel="stylesheet" href="style.css"></head>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
