Assignment 2.2 — Personal Introduction Page
Task: Create a resume-style webpage to introduce yourself.
What to do:

1. Write your name in the main heading.
2. Write an introduction paragraph in the About Me section.
3. Create sections for education, skills, and hobbies.
4. Use `h1` to `h6` headings in appropriate places.
5. Use `p` for paragraphs, `br` for line breaks, and `hr` for separators.
6. Use `strong`, `em`, and `i` for important text.
7. Organize related content using `div` and inline content using `span`.
Submission: The personal introduction webpage and its HTML code.

---

## Answer / Implementation

**Approach:** Personal introduction. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<main>
  <h1>Your Name</h1><p>Student and aspiring web developer.</p>
  <h2>About Me</h2><p>I am learning HTML, CSS, and JavaScript.</p>
  <h2>Education</h2><p>Add your course and college here.</p>
  <h2>Skills</h2><ul><li>HTML</li><li>Problem solving</li></ul>
  <h2>Contact</h2><p>you@example.com</p>
</main>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
