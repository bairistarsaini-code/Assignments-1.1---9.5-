Assignment 2.1 — First HTML Page
Task: Create a basic HTML webpage with a title and headings.
What to do:

1. Create an `index.html` file.
2. Use `<!DOCTYPE html>`, `html`, `head`, and `body` elements.
3. Set the page title to "My First Webpage".
4. Add a main heading and at least 3 subheadings.
5. Use HTML comments and proper indentation.
6. Verify by opening the page in a browser.
Submission: The `index.html` file and a browser screenshot.

---

## Answer / Implementation

**Approach:** Basic HTML page. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<!doctype html>
<html lang="en">
<head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0"><title>My First Page</title></head>
<body><h1>My First Webpage</h1><h2>About This Page</h2><p>This is my first HTML page.</p></body>
</html>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
