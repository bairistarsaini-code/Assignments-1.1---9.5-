Assignment 2.5 — HTML Foundations Mini-Project
Task: Build a complete personal introduction webpage from scratch.
Required sections:
- Page title and heading
- About Me
- Education
- Technical Skills
- Hobbies
- Contact Information
Rules:

1. Use only HTML; CSS is not required.
2. Use correct document structure and semantic headings.
3. Arrange sections in a clean order.
4. Save the HTML file named `index.html`.
5. Commit the final code to a Git repository.
Submission: The complete personal introduction webpage, HTML file, and GitHub link.

---

## Answer / Implementation

**Approach:** Personal introduction mini-project. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<!doctype html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>My Portfolio</title></head>
<body><header><h1>Your Name</h1><p>Student | Beginner Developer</p></header><main><section><h2>About</h2><p>I enjoy learning technology and building websites.</p></section><section><h2>Education</h2><p>Add your qualification here.</p></section><section><h2>Skills</h2><ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul></section><section><h2>Contact</h2><a href="mailto:you@example.com">Email me</a></section></main></body></html>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
