Assignment 3.5 — Blog / Portfolio Mini-Project
What to build: A personal blog or portfolio website.
Required sections:
- Header with name/logo
- Navigation bar
- About Me
- Skills or Interests
- Blog posts or projects
- Images
- Useful links
- Footer with contact details
Rules:

1. Use links, images, and lists in HTML.
2. Use semantic tags.
3. Navigation links must be working.
4. Code must be clean and properly indented.
5. You can divide the website into multiple HTML files.
Submission: Complete blog/portfolio project, source code, and GitHub repository link.

---

## Answer / Implementation

**Approach:** Blog / portfolio. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<header><h1>My Portfolio</h1><nav><a href="#about">About</a> <a href="#projects">Projects</a> <a href="#contact">Contact</a></nav></header><main><section id="about"><h2>About Me</h2><p>I am learning to build accessible websites.</p></section><section id="projects"><h2>Projects</h2><article><h3>First Website</h3><p>A basic HTML project.</p></article></section><section id="contact"><h2>Contact</h2><a href="mailto:you@example.com">Email</a></section></main><footer>© 2026</footer>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
