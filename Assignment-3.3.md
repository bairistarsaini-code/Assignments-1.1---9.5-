Assignment 3.3 — Ordered, Unordered & Nested Lists
What to build: A webpage containing information about your college or course.
Steps:

1. Write an introduction for the college/course.
2. Make a list of departments or subjects using `<ul>`.
3. Show the admission process using `<ol>`.
4. Arrange topics of any subject in a nested list.
5. Use `<dl>`, `<dt>`, and `<dd>` for details of teachers or courses.
6. Organize the page through headings and sections.
Submission: The `college-info.html` file and a browser screenshot.

---

## Answer / Implementation

**Approach:** Lists. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<h1>My Course</h1><ol><li>Learn HTML</li><li>Learn CSS</li></ol>
<h2>Topics</h2><ul><li>Frontend<ul><li>HTML</li><li>CSS</li></ul></li><li>Programming</li></ul>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
