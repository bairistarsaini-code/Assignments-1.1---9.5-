Assignment 3.2 — Images in HTML
What to build: An images section on your portfolio page.
Steps:

1. Create a folder named `images` in your project.
2. Add at least 3 images.
3. Use `src`, `alt`, `width`, and height as required in the `<img>` tag.
4. Keep image paths correct.
5. Write a meaningful alt text for each image.
6. Check that images are loading properly in the browser.
Submission: Portfolio page and the images folder. Each image must have a meaningful alt text.

---

## Answer / Implementation

**Approach:** Accessible images. Create the file(s) requested in the task, paste/adapt the example, save, and open the HTML page in a browser. Replace sample personal details and image paths with your own. Check all links and required fields before taking the submission screenshot.

```html
<section><h2>My Portfolio</h2>
  <figure><img src="images/project.jpg" alt="Screenshot of my web project" width="400"><figcaption>My first project</figcaption></figure>
</section>
```

**Verification:** Open the page in Chrome, test links or form controls, and capture the completed page. For HTML validation, fix missing closing tags, duplicate IDs, missing `alt` text, and invalid nesting.
